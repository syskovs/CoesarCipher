# CoesarCipher

GUI/CLI утилита для шифрования и дешифровки текста алгоритмом Цезаря на Windows.
Поддерживает русский (33 буквы, с Ё) и английский алфавиты, работу с файлами,
пакетную обработку каталогов и мгновенное копирование результата в буфер обмена.

Один исполняемый файл работает в двух режимах: двойной клик открывает окно,
запуск из терминала с аргументами — выполняет команду и печатает результат
в консоль.

## Возможности

- Шифрование и дешифровка с произвольным целым ключом (в т.ч. отрицательным)
- Русский и английский алфавиты, сохранение регистра букв
- Символы вне алфавитов (цифры, пробелы, пунктуация) проходят без изменений
- **GUI на WPF:** автообработка, копирование в буфер одной кнопкой, загрузка/сохранение файлов, пакетная обработка папки
- **CLI:** поддержка `--text`, `--in`/`--out`, чтение из pipe (stdin), коды возврата для скриптов
- Один self-contained `.exe` — не требует установленного .NET на машине пользователя

## Системные требования

- Windows 10 / 11 x64
- Установленный .NET **не требуется** (сборка self-contained, runtime внутри `.exe`)

## Установка

Скачайте `CoesarCipher.exe` с [страницы релизов](https://github.com/<username>/CoesarCipher/releases/latest)

## Использование

### GUI

Запустите `CoesarCipher.exe` двойным кликом. В окне:

1. Введите исходный текст в поле «Исходный текст».
2. Укажите ключ (целое число) и режим (Шифровать / Дешифровать).
3. Результат отображается автоматически.
4. Нажмите «Копировать результат» — текст помещается в буфер обмена.

Кнопки «Загрузить из файла…», «Сохранить результат…» и «Пакетная обработка
папки…» позволяют работать с файлами.

### CLI

```powershell
# Шифрование строки
CoesarCipher.exe -e -k 3 -t "Привет, мир!"

# Дешифровка файла
CoesarCipher.exe -d -k 3 -i secret.txt -o plain.txt

# Пакетная обработка папки
CoesarCipher.exe -e -k 5 -b .\input --out-dir .\output

# Чтение из pipe
echo Hello | CoesarCipher.exe -e -k 2

# Справка
CoesarCipher.exe --help
```

| Флаг | Длинная форма | Назначение |
|---|---|---|
| `-e` | `--encrypt` | Режим шифрования |
| `-d` | `--decrypt` | Режим дешифровки |
| `-k N` | `--key N` | Ключ (целое число) |
| `-t S` | `--text S` | Текст для обработки |
| `-i F` | `--in F` | Прочитать ввод из файла |
| `-o F` | `--out F` | Записать результат в файл |
| `-b D` | `--batch D` | Пакетная обработка папки `D` |
|   | `--out-dir D` | Папка для результатов пакетной обработки |
| `-h` | `--help` | Справка |

Коды возврата CLI: `0` — успех, `1` — ошибка аргументов, `3` — ошибки пакетной обработки.

> **Примечание.** При запуске CLI-режима из `cmd.exe` вывод появляется после
> возврата приглашения (особенность `WinExe`). Запускайте из PowerShell или
> используйте `start /wait CoesarCipher.exe ...`.

## Сборка из исходников

Требуется .NET 10 SDK.

```powershell
git clone https://github.com/<username>/CoesarCipher.git
cd CoesarCipher
dotnet publish -c Release -r win-x64 -o .\publish
```

Готовый `CoesarCipher.exe` (~62 МБ, self-contained) появится в папке `publish\`.

Для разработки:

```powershell
dotnet build
dotnet run
```

## Структура проекта

```
CoesarCipher/
├── Core/                       # Алгоритм (без зависимостей от WPF и Console)
│   ├── Alphabet.cs             # Русский и английский алфавиты
│   ├── CaesarCipher.cs         # Шифр + enum CipherMode
│   └── BatchProcessor.cs       # Пакетная обработка каталога
├── Cli/
│   └── CliRunner.cs            # Парсер аргументов, AttachConsole
├── App.xaml / App.xaml.cs      # Точка входа: маршрутизирует GUI ↔ CLI
├── MainWindow.xaml / .xaml.cs  # Окно WPF
└── CoesarCipher.csproj
```

Слой `Core` не зависит от WPF и Console — переиспользуется и в GUI, и в CLI.
GUI и CLI вызывают одни и те же публичные методы, дублирование логики отсутствует.
